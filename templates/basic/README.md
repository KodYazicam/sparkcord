# sparkcord-bot

Starter generated by [sparkcord](https://github.com/KodYazicam/sparkcord).

```bash
cp .env.example .env
# fill DISCORD_TOKEN (and optionally DEV_GUILD_ID, OWNER_IDS)
npm install
npm start
```

Node 22+ runs TypeScript via `--experimental-strip-types`. On Node 20 use `npm run start:tsx` after `npm i -D tsx`.
