# sparkcord-bot

Starter generated by [sparkcord](https://github.com/KodYazicam/sparkcord).

## Requirements

- Node.js **22.6+**
- A Discord bot token ([Developer Portal](https://discord.com/developers/applications))
- Privileged **Message Content Intent** if you want `!ping` prefix commands
- Invite the bot with scopes `bot` and `applications.commands`

## Setup

```bash
cp .env.example .env
```

Edit `.env`:

```env
DISCORD_TOKEN=your-bot-token
DEV_GUILD_ID=optional-server-id-for-instant-slash-commands
OWNER_IDS=optional,comma,separated,user,ids
```

```bash
npm install
npm start
```

`npm start` runs:

```text
node --env-file=.env --experimental-strip-types src/index.ts
```

`src/load-env.ts` also parses `.env` so missing `--env-file` still works.

## Layout

```
src/
  index.ts           Client, sparkcord attach, login
  load-env.ts        Minimal .env parser (no dotenv package)
  commands/ping.ts   Slash + prefix, 3s cooldown
  events/ready.ts    Logs the bot tag
```

Add a command: new file under `src/commands/` that `export default { name, description, run }`. Restart the process. With `DEV_GUILD_ID` set, slash commands refresh immediately.

## Intents

`Guilds`, `GuildMessages`, `MessageContent`. Turn Message Content on in the portal or prefix commands will be ignored.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `Missing DISCORD_TOKEN` | `.env` not copied or empty |
| Slash commands missing | Set `DEV_GUILD_ID`; re-invite with `applications.commands` |
| `!ping` ignored | Message Content Intent off |
| Node 20 error | This template needs 22.6+. The sparkcord **library** still supports 20 |
