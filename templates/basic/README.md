# sparkcord-bot

Starter generated by [sparkcord](https://github.com/KodYazicam/sparkcord).

```bash
cp .env.example .env
# fill DISCORD_TOKEN (and optionally DEV_GUILD_ID, OWNER_IDS)
npm install
npm start
```

Requires **Node 22.6+**. `.env` is loaded by `src/load-env.ts` (and `--env-file` on start).
